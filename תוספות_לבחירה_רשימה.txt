# מיני פרויקט במערכות חלונות - מערכת ניהול משלוחים

## ✅ תוספות שהוטמעו בפרויקט

### 🎨 שכבת התצוגה PL - שיפורי WPF מתקדם

1. **ControlTemplate (1 נק')**
   - 📁 מיקום: `PL\Courier\OpenOrdersForCourierWindow.xaml`
   - תיאור: ControlTemplate מותאם אישית לכפתורים (`ModernButton`, `SmallButton`)
   - כולל אפקטים של hover, pressed ו-shadow effects
   - קוד לדוגמה: שורות 16-60 ב-OpenOrdersForCourierWindow.xaml

2. **IMultiValueConverter (1 נק')**
   - 📁 מיקום: `PL\Converters.cs`
   - תיאור: המרות מרובות ערכים
   - מימושים:
     * `CourierStatusConverter` - סטטוס שליח על פי IsActive ו-OrderInProgress
     * `CourierListStatusConverter` - סטטוס ברשימת שליחים
   - קוד לדוגמה: שורות 55-100 ב-Converters.cs

3. **ולידציה משולבת ב-Binding (1 נק')**
   - 📁 מיקום: `PL\ValidationRules\`
   - תיאור: ValidationRules המשולבים ב-XAML Bindings
   - מימושים:
     * `EmailValidationRule` - בדיקת פורמט אימייל
     * `IsraeliIdValidationRule` - בדיקת תעודת זהות
     * `PhoneValidationRule` - בדיקת מספר טלפון
     * `RequiredStringValidationRule` - בדיקת שדה חובה
   - דוגמה לשימוש: בחלונות הוספה/עריכה של שליחים והזמנות

4. **טרנספורמציות - Transformation (1 נק')**
   - 📁 מיקום: `PL\Courier\OpenOrdersForCourierWindow.xaml`
   - תיאור: שימוש ב-ScaleTransform לאפקט לחיצה על כפתור
   - קוד לדוגמה:
     ```xml
     <Setter Property="RenderTransform">
         <Setter.Value>
             <ScaleTransform ScaleX="0.98" ScaleY="0.98"/>
         </Setter.Value>
     </Setter>
     ```

5. **אייקון בחלון ובשורת המשימות (1 נק')**
   - 📁 מיקום: `PL\Resources\delivery_icon.ico`
   - תיאור: אייקון משאית משלוחים מותאם אישית
   - מופיע בכל חלונות האפליקציה
   - מוטמע גם בקובץ ההרצה (.exe)
   - קבצים:
     * delivery_icon.ico - פורמט ICO
     * delivery_icon.png - פורמט PNG
     * AppIcon.xaml - פורמט וקטורי XAML

### 🗺️ שיפורי PL הקשורים לנושא הפרויקט

6. **מפה אינטראקטיבית עם מיקומים (5 נק')**
   - 📁 מיקום: `PL\Courier\OpenOrdersForCourierWindow.xaml.cs`
   - תיאור: מפה אינטראקטיבית עם Leaflet.js
   - תכונות:
     * הצגת מיקום החברה (נקודת התחלה)

     * עדכון דינמי בבחירת הזמנה מהרשימה
     * פאנל מידע עם סוג רכב ומרחק
   - קוד: `ShowLeafletMap()` + `ShowMapForSelection()`

7. **קווים אוויריים על המפה (2 נק')**
   - 📁 מיקום: `PL\Courier\OpenOrdersForCourierWindow.xaml.cs`

   - צבע הקו משתנה לפי סוג הרכב:
     * 🚗 מכונית - כחול (#2E86DE)
     * 🏍️ אופנוע - סגול (#8E44AD)
     * 🚴 אופניים - ירוק (#27AE60)
     * 🚶 רגלית - כתום (#E67E22)
   - קוד לדוגמה: שורות 280-295 ב-ShowLeafletMap()

8. **כפתור מחיקה/ביטול מותנה (2 נק')**
   - 📁 מיקום: `PL\Converters.cs`
   - תיאור: `OrderStatusToCancelVisibilityConverter`
   - כפתור Cancel מופיע רק כאשר אפשר לבטל הזמנה
   - תנאי: OrderStatus == Scheduled או InTreatment
   - מונע טעויות משתמש וממשק נקי יותר

### 🔐 שכבת הלוגיקה BL

9. **שליחת אימייל (3 נק')**
   - 📁 מיקום: `BL\Helpers\EmailSender.cs`
   - תיאור: מערכת שליחת אימיילים לשליחים
   - תכונות:
     * שליחה כאשר הזמנה משוייכת לשליח

### 💾 שכבת הנתונים DAL

10. **Singleton Thread Safe עם Lazy Initialization (2 נק')**
    - 📁 מיקום: `DalList\DalList.cs`, `DalXml\DalXml.cs`
    - תיאור: מימוש Singleton מאובטח לריבוי תהליכונים

    - קוד לדוגמה:
      ```csharp

      private DalList() { }
      ```

## 💡 הערות למרצה/בודק

1. **שימוש באייקון**: האייקון מופיע בכל החלונות - ניתן לבדוק ע"י הרצת האפליקציה והסתכלות על:
   - כותרת החלון (שורת הכותרת)
   - שורת המשימות (Taskbar)
   - קובץ ה-EXE עצמו

2. **מפות Leaflet**: המפות פועלות עם WebBrowser ו-Leaflet.js - דורש חיבור אינטרנט לטעינת הספריות.

3. **אימיילים**: האימיילים נשמרים בתיקייה `bin\mails` כקבצי .eml - ניתן לפתוח עם Outlook או כל קורא מייל.

4. **Singleton Thread Safe**: ההטמעה משתמשת ב-Lazy Initialization של C# עם property initialization - זה Thread Safe לפי התיעוד של Microsoft.
